# Portfolio Reference Gallery

Classroom gallery of 15 entertainment-design portfolio references (concept, vis-dev, BG/layout, emerging), styled to the pLAtform design system for the Ryman Arts curriculum site.

## Run
npm install
npm run dev

## Deploy
Netlify: connect repo, build `npm run build`, publish `dist` (netlify.toml included).

## Edit content
All content lives in the `ARTISTS`, `CATEGORIES`, and `PATTERN` arrays at the top of
`src/PortfolioReferenceGallery.jsx`. Paste each artist's real portfolio link into `url`
to replace the "Search for the site" fallback with an "Open portfolio" button.
